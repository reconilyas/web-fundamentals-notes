# Frontend, Backend and API

## Frontend

Frontend is the part of a website that users can see and interact with directly.

Examples:
- Web pages
- Buttons
- Forms
- Images
- Layout and design
- User interface (UI)

Frontend runs mainly in the user's browser and is built using technologies such as:

- HTML
- CSS
- JavaScript

---

## Backend

Backend is the part of a website that works behind the scenes.

It is responsible for:

- Processing user requests
- Managing application logic
- Storing and retrieving data
- Communicating with databases
- Handling authentication and authorization

Examples of backend data:

- User accounts
- Search history
- Orders
- Messages

Backend applications run on servers using programming languages such as:

- JavaScript (Node.js)
- Python
- Java
- PHP
- C#

---

## API (Application Programming Interface)

API stands for:

**Application Programming Interface**

An API is a way for different software components to communicate with each other.

In web applications, APIs allow the frontend to communicate with the backend.

Example:

1. User clicks "Login" on the frontend.
2. Frontend sends a request to the API.
3. API processes the request through the backend.
4. Backend checks the database.
5. API sends a response back to the frontend.

Example communication:
Frontend → API → Backend → Database
Database → Backend → API → Frontend


APIs commonly exchange data using formats such as:

- JSON
- XML
